# MovieHub — лабораторные работы по веб-программированию

Единый многостраничный портал о кино на HTML, CSS и TypeScript. Каждая новая лабораторная расширяет проект. Клиентская часть собирается через Vite, а полноценная авторизация работает на Node.js, Express и SQLite.

## Запуск

```bash
npm install
npm run dev
```

Команда одновременно запускает Vite и API. Откройте адрес, который выведет Vite (обычно `http://localhost:5173`). База автоматически появится в `data/moviehub.db` и не попадёт в Git.

Для запуска собранной версии:

```bash
npm run build
npm start
```

Затем откройте `http://127.0.0.1:3000`.

## Проверка и сборка

```bash
npm run typecheck
npm run build
npm run check
```

## Страницы

- `index.html` — главная страница, слайд-шоу и видео.
- `movies.html` — каталог и жанры.
- `about.html` — информация о портале и учебные примеры.
- `auth.html` — формы входа и регистрации с клиентской и серверной валидацией.
- `profile.html` — защищённый личный кабинет и выход из аккаунта.

## Лабораторная №2

| Требование | Реализация |
| --- | --- |
| Форма авторизации/регистрации | Две переключаемые формы на `auth.html` |
| `:focus` | Активное поле получает светлую рамку и фон |
| `:valid` / `:invalid` | После взаимодействия поля подсвечиваются зелёным или красным |
| `:required` / `:optional` | Обязательные и необязательные поля имеют разный левый край |
| HTML-валидация | `required`, `type`, `pattern`, `minlength`, `maxlength`, `min`, `max` |
| Проверка по маске | Телефон форматируется как `+7 (999) 999-99-99` |
| Минимум и максимум | Возраст 14–100, пароль 8–24, текстовые ограничения длины |
| Имя и фамилия | Только буквы, первая заглавная, остальные строчные |
| JavaScript/DOM | TypeScript обрабатывает события, ошибки, запросы и переход в профиль |
| Серверная валидация | Критичные правила повторяются в Express API |
| Регистрация и вход | Пользователь сохраняется в SQLite и может повторно войти |
| Пароли | В базе хранится bcrypt-хеш, открытый пароль не сохраняется |
| Сессия | Случайный токен передаётся в `HttpOnly`, `SameSite=Lax` cookie; в SQLite хранится только его SHA-256-хеш |
| Защита | Helmet добавляет HTTP-заголовки, попытки входа и регистрации ограничены по частоте |
| Профиль и выход | `/profile.html` загружает текущего пользователя через API и позволяет завершить сессию |

### API авторизации

| Метод и путь | Назначение |
| --- | --- |
| `POST /api/auth/register` | Создать аккаунт и сессию |
| `POST /api/auth/login` | Войти по email и паролю |
| `GET /api/auth/me` | Получить текущего пользователя |
| `POST /api/auth/logout` | Завершить текущую сессию |
| `GET /api/health` | Проверить работу сервера |

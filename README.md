# MovieHub — лабораторная работа №1

Простой многостраничный портал о кино на HTML, CSS и TypeScript. Проект собран через Vite без использования фреймворков и бэкенда.

## Запуск

```bash
npm install
npm run dev
```

После запуска откройте адрес, который выведет Vite (обычно `http://localhost:5173`).

## Проверка и сборка

```bash
npm run typecheck
npm run build
npm run check
```

## Страницы

- `index.html` — главная страница, слайд-шоу и видео.
- `movies.html` — каталог и жанры.
- `about.html` — информация о портале и учебные примеры.

## Соответствие заданию

| Пункт | Реализация |
| --- | --- |
| 1.1 | На страницах используются заголовки `h1`–`h6` |
| 1.2 | Текст и блоки размечены через `p`, `span`, `div` |
| 1.3 | Используются `em` и `strong` |
| 1.4 | В приветственном тексте есть перенос `br` |
| 1.5 | На страницах есть списки `ol` и `ul` |
| 1.6 | Локальные изображения SVG и видео MP4 |
| 1.7 | Ссылки размечены тегами `a` |
| 1.8 | Есть якорная навигация по разделам страницы |
| 1.9 | Главное меню связывает три HTML-страницы |
| 2.1 | Внешний CSS, блок `style` в `movies.html`, inline-стиль в `about.html` |
| 2.2 | Карточки демонстрируют `background`, `border`, `margin`, `padding` |
| 2.3 | Применяются селекторы тегов и классов |
| 2.4 | Цвет текста карточек демонстрирует наследование и каскадирование |
| 2.5 | Локальный FilmSans, внешний Oswald и системные шрифты |
| 2.6 | CSS-анимации, hover-эффекты и переходы |
| 2.7 | Фиксированное выдвижное меню работает на TypeScript |
| 2.8 | На главной странице работает слайд-шоу |
